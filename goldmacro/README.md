## 面板上每一粒掣

| 掣 | 做什麼 |
|---|---|
| REC | 開始或者停止錄製,錄完自動存檔 |
| REPLAY | 重播現在揀住那一格 |
| STOP | 停,連續三下 ESC 是緊急停 |
| PAUSE | 暫停同繼續 |
| RENAME | 改那一格的名字,雙擊名字一樣得 |
| EXPORT | 另存一份帶時間的 json |
| CLEAR | 清空全部格,連磁碟那份一齊清 |
| SPD - / + | 播放速度 0.25x 到 4.00x |
| RUNS - / + | 要跑幾多次,0 是永遠 |
| GAP - / + | 每一轉之間等幾耐,跟住單位加減 |
| FADE - / + | 視窗透明度 |
| DETAILS | 打開步驟編輯器,見下面 |
| SAVE | 即刻存,連可讀的 txt 一齊寫 |
| LOAD | 由 library 資料夾重新讀返所有格 |
| FOLDER | 開 library 資料夾 |
| JITTER | 關 → 8ms/1px → 18ms/2px → 35ms/4px → 關 |
| GAP UNIT | 秒 → 分 → 小時 → 日,按一下轉一個 |
| IMPORT | 揀一個 json 讀入現在那一格 |

## DETAILS 步驟編輯器

## 左邊一行一步,右邊改那一步。錄返來的同自己砌的完全一樣,同一個編輯器,沒有分別。

| 掣 | 做什麼 |
|---|---|
| APPLY | 把右邊改好的值寫返落那一步 |
| + WAIT | 在現在那一步後面插一個等待 |
| DELETE | 刪那一步 |
| UP / DOWN | 上移下移 |
| + TYPE | 插一個打字步驟,自己填要打的字 |
| + KEYS | 插一個組合鍵步驟,例如 ctrl+c |
| + FOCUS | 插一個切換視窗步驟,填視窗標題其中幾個字 |
| COPY | 直接插 ctrl+c |
| PASTE | 直接插 ctrl+v |
| SELECT ALL | 直接插 ctrl+a |
| COPY STEP | 複製現在那一步 |
| SAVE | 即刻寫落磁碟 |
| CLOSE | 關窗 |

## 等待那一步,數字自己填,單位撳一下就轉:秒、分、小時、日。上限七日 —— 再長那件事叫排程,不叫巨集。

## 一個等待不是一件送出去的事件,它只是把它後面所有步驟的時間推遲。所以插一個 2 秒等待,前面的一步不動,後面每一步都遲 2 秒。

## macro 不只是點擊

## 除了錄返來的滑鼠鍵盤,可以自己插這四種步驟:

| 步驟 | 做什麼 |
|---|---|
| WAIT | 等一段時間,秒分時日 |
| TYPE | 逐個字打出來,不經剪貼簿,所以不會搶走你複製了的東西 |
| KEYS | 一個組合鍵,ctrl+c、ctrl+v、ctrl+a、alt+tab 都得 |
| FOCUS | 先切換去某個視窗,標題含有那幾個字就中 |

## TYPE 同 KEYS 不是新的事件類型 —— 播放之前它們會展開成真正的按鍵事件,行的是同錄返來的按鍵一模一樣那條路,所以在任何程式裡面行為都一樣。

## FOCUS 例外,它不是輸入,所以由播放器自己處理:找到那個視窗就抬起來,找不到就在面板寫一行,不會靜靜跳過。

## 選取文字有兩條路:拖曳選取本身錄得到,整版選取用 SELECT ALL。

## 鍵盤

| 按鍵 | 做什麼 |
|---|---|
| CTRL+1 到 CTRL+6 | 揀第幾格 |
| ESC 連按三下 | 緊急停 |

## 其餘四個熱鍵印在掣上面,撳 KEYBINDS 那一行的格仔再按新組合就改得到,RESET 還原。

## v3 同 v4 的分別

| 項目 | v3 | v4 |
|---|---|---|
| 關掉之後 | 全部不見 | 自動存,開返就在 |
| 可讀檔 | 沒有 | 每一格一個 txt |
| 看得到裡面有什麼 | 看不到 | DETAILS 一行一步 |
| 改一粒點擊 | 要重錄 | 改座標、時間、按鍵 |
| 等待 | 沒有 | 秒分時日,插在任何位置 |
| 每轉之間等幾耐 | 只有秒,封頂 5 秒 | 四個單位,封頂七日 |
| 加減步驟 | 沒有 | 插入、複製、刪除、上移下移 |
| 讀返別處的檔 | 沒有 | IMPORT |
| 播放像不像人手 | 永遠一模一樣 | JITTER 三級 |
| 打字 | 沒有 | TYPE 步驟 |
| 複製貼上 | 沒有 | COPY / PASTE / SELECT ALL |
| 組合鍵 | 沒有 | KEYS,自己寫 |
| 切換視窗 | 沒有 | FOCUS |

## 要知道的事

## 錄製上限同 v3 一樣,錄得太長會自己封頂。

## 播放之前它會等你的手指真的離開 CTRL,不是等一個固定秒數 —— 否則第一個按鍵會變成 CTRL+那個鍵。

## JITTER 開了就不再是逐格精準,要準就關掉它。

## 一個 library 檔壞了不會令工具開不到,它會跳過那一個繼續開。
