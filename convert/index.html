What it does

Drop a file into the panel. The extension reads the header to work out what the file really is, shows you what it can become, and does the work inside the tab you already have open. There is no upload step, no queue, and no account.

  • Any file becomes a PNG that carries every byte, and that PNG turns back into the original file under its original name.
  • PNG, JPG, WebP and BMP in every direction.
  • JSON to pretty, to minified, or to CSV. CSV back to JSON.
  • Any text to Base64 or to hexadecimal.
  • 777 extensions across 26 families are recognised by their magic bytes, so a wrong file extension does not fool it.

The pixel carrier

A file is a list of bytes and a byte is a number from 0 to 255. A colour channel is also a number from 0 to 255, so one RGB pixel holds exactly three bytes.

The first pixels carry a small header with the original filename and the original length, which is why restoring gives back the right name and not one byte more. Nothing is compressed and nothing is guessed, so the round trip is identical byte for byte. A 300,000 byte file becomes a 317 by 316 image and comes back the same.

What it cannot see

The manifest declares no permissions, no host_permissions and no content_scripts. It cannot read the pages you visit, cannot see your history, cannot touch your cookies, and cannot make a request on your behalf. There is no analytics and no telemetry.

Your files never leave your machine, because there is nowhere for them to go. The full policy is at newgod.vip/privacy.

Known limits

  • Your own machine is the ceiling. Files are read one megabyte at a time so a large file never sits in memory whole, but a browser tab still has a limit and a very large board plus a very large file will find it.
  • A PNG made by the carrier only restores through this extension. It is a real PNG and it will open in any viewer, but the bytes it carries mean nothing to anything else.
  • Editing a carrier PNG in an image editor destroys it. Re-saving changes pixels, and a changed pixel is a changed byte.
  • The animation and the editor settings live in your own browser storage. Clearing your browsing data clears them, and they do not follow you to another computer.
