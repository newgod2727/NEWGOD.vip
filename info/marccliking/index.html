GOLDMACRO v4.1

A mouse and keyboard recorder for Windows that replays what it caught at human timing, not at machine timing. v4 is the version that stopped forgetting: v3 held the whole session in RAM and lost every recording the moment you closed it.

What did not change

Recording accuracy, the replay engine, the panel it draws, the six slots, the keybinds and the panic stop are all v3’s. v4 is a layer on top, not a rewrite — which is why the whole v3 test suite still passes untouched.

The details window

What v3 never had: a way to look inside a slot. Left is every step, one line each. Right edits the step you picked.

A recorded macro and a hand-built one are the same thing here

There is no separate “edit mode” and no second format. A slot is a list of steps whether it came from REC or from pressing + WAIT eight times, so every button on this window works on both.

what a step looks like
1 0.000 PRESS left at 812, 344 2 0.084 RELEASE left at 812, 344 3 0.084 WAIT 2 secs 4 1.203 KEYDOWN e

That is the same text the editor lists and the same text the .txt export writes, on purpose — so what is on screen and what is in the file can never drift apart.

Editing is refused while a macro is running — it says so rather than silently ignoring the click.

Waiting, in the unit you think in

Type the number, click the unit. Seconds, minutes, hours, days.

A wait is not an event

The player runs on absolute offsets from the start of a run, so a wait is not something sent to Windows. It is folded into the timing of every step after it. Insert a 2 second wait and the step before it does not move; every step after it happens 2 seconds later.

This is why a wait costs nothing at replay time and why it can sit anywhere in the list, including at the very top.

Between runs

The gap between one run and the next uses the same four units. GAP UNIT picks the unit and then one press of GAP + adds one of those — one hour per press when the unit is hours, rather than five hundredths of a second.

 v3v4
Step size0.05 s always0.05 s, 1 min, 1 hour or 1 day
Ceiling5 seconds7 days
Shown as0.20s1 hour

Seven days is the cap on purpose. Anything longer is a scheduler, not a macro.

A macro is not only clicking

Recording catches the mouse and the keyboard. These four steps are the things you add by hand, for the parts a recording cannot express.

The four

StepWhat it does
WAIThold for a number of seconds, minutes, hours or days
TYPEwrite words, one character at a time
KEYSone combination — ctrl+c, ctrl+v, ctrl+a, alt+tab
FOCUSswitch to a window whose title contains what you typed

COPY, PASTE and SELECT ALL are on the window as their own buttons. They insert a KEYS step with the combo already filled in, so there is nothing to remember.

Typing does not touch your clipboard

A TYPE step is sent as key presses, not pasted. Doing it through the clipboard would be shorter to write and would quietly throw away whatever you had copied — so it types.

what a copy-paste macro looks like
1 0.000 FOCUS window with Notepad in the title 2 0.000 KEYS ctrl+a 3 0.000 KEYS ctrl+c 4 0.000 FOCUS window with Chrome in the title 5 0.000 KEYS ctrl+v 6 0.000 WAIT 2 secs 7 0.000 TYPE done

Why they behave the same everywhere

TYPE and KEYS are not a new kind of event. Before a run they are expanded into ordinary key presses and travel exactly the path a recorded key takes, which is why a program cannot tell them apart from you.

FOCUS is the one exception, because switching window is not input. The player handles it, and if no window matches it says so on the panel instead of skipping quietly.

Selecting text works two ways: dragging across it is captured by the recorder like any other drag, and selecting everything is SELECT ALL.

Two files per macro

One the tool reads back, one you can read.

The folder

library
%LOCALAPPDATA%\GoldMacro\library\slot1.json %LOCALAPPDATA%\GoldMacro\readable\slot1.txt

The json is what comes back when you open the tool. The txt is the same macro written out for a human — name, length, how much of it is waiting, then every step.

It saves without being asked

Every recording writes itself the moment it stops, and every edit in the details window writes again. Nothing waits for you to remember a save button. SAVE is there for when you want to be sure, not because it is required.

A file that will not parse is skipped rather than fatal — one corrupt slot can never stop the tool from opening. That case is covered by a test.
